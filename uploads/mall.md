# 商城
## CATEGORY, 分类，支持树型
- CATEGORY ID, UUID, PRIMARY
- PARMENT CATEGORY ID, UUID, default 0, REQUIRED
- CATEGORY NAME, String, REQUIRED, UNIQUE
- LINK TARGET TYPE，enum
- LINK TARGET ID，UUID
- ATTRIBUTE_OPTIONS, JSONB
 
**约束**
- LINK TARGET TYPE标识本类别属性由link目标实体管理，link的目标由程序控制
- LINK TARGET ID目标对应的对象，比如link到DeviceModels中的N950型号

## PRODUCT, 产品
- PRODUCT ID, UUID, PRIMARY
- CATEGORY ID, UUID, REQUIRED, FK
- PRODUCT NAME, REQUIRED, UNIQUE
- DESCRIPTION, JSONB
- ATTRIBUTE_OPTIONS, JSONB
- PRODUCT TYPE, String, enum("BUNDLE", "SINGLE")
- STATUS, String, enum("ACTIVE", "INACTIVE")

## SKU, 产品库存
- SKU ID, UUID, PRIMARY
- PRODUCT ID, UUID, FK
- PRICE, DECIMAL
- ATTRIBUTES, JSONB
- STATUS, String, enum("ACTIVE", "INACTIVE")

## BUNDLE ITEM, SKU清单，用于 Bundle 模式
- BUNDLE ITEM ID, UUID, PRIMARY
- BUNDLE SKU ID, UUID, FK
- COMPONENT SKU ID, UUID, FK
- QUANTITY, INT

## ORDER, 订单
- ORDER ID, PRIMARY
- PARTY ID, ID, FK
- ORDER TYPE, String, enum("SAMPLE DEVICE", "PRODUCT DEVICE")
- ORI AMOUNT, DECIMAL, REQUIRED, 订单原价
- DISCOUNT PERCENT, DECIMAL, 折扣百分比
- DISCOUNT AMOUNT, DECIMAL, 折扣金额
- TOTAL AMOUNT, DECIMAL, 最后金额
- SHIPPING, JSONB,收件信息
- REMARK
- STATUS, String, enum("PENDING PAYMENT", "PENDING SHIP", "SHIPPED", "DELIVERED", "CANCELLED", "REFUNDED")

**约束**
- DISCOUNT PERCENT 和 DISCOUNT AMOUNT 只能二选一，不能同时生效
- STATUS 状态机
    - PENDING PAYMENT: 初始状态，等待付款
    - PENDING SHIP: 等待发货，免费/客户完成付款
    - DELIVERED: 已交付, 上个状态: SHIPPED
    - CANCELLED: 订单取消, 上个订单: PENDING PAYMENT/PENDING SHIP
    - REFUNED: 已退款，上个状态: PENDING SHIP/DELIVERED

## ORDER ITEM, 订单的商品明细
- ORDER ITEM ID, UUID, PRIMARY
- ORDER ID, UUID
- SKU ID, UUID, 
- ORI PRICE, DECIMAL, 原商品价格
- QUANTITY, INT, 商品数量
- AMOUNT, DECIMAL, 商品小计金额
- BUNDLE ITEMS, JSONB(Array<JSON>), 组合商品的明细
    - name
    - quantity
    - attributes
    - skuId
    - productId
    - sns, JSONB(Array<JSON>)
        - sn
