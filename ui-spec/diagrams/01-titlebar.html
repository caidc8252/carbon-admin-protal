标题栏统一模板 · 五个标准形态

全站标题栏统一为一套模板（原型 = Ticket 详情标题栏）：纯白底、非卡片、底部 1px 横线，固定不滚。 行布局 [返回] [实体图标] [eyebrow / 标题+徽章 / 副标题 / meta] ··· [操作]，操作恒在最右，遵循 CTA 唯一性（§0）。 按需启用插槽，缺省自动收起。§1：全站只保留一层主标题——由标题栏承载，正文不再写 26px 大标题，面包屑只给路径。

本页对应 §8.3 的五个形态 A/B/C/D/E + E′。底部行（Tab / 步骤 / 状态轨）三选一、同一时刻只放一种；步骤/状态轨画法见 07-stepper.html（变体 B）。
