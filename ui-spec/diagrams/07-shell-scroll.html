滚动唯一性（标题栏以下）

.content 是唯一的 overflow:auto 容器。搜索/条件区不吸顶（随内容滚走）；只有 list-head 计数行 + thead 表头吸顶，pin 到 .content 顶部（紧贴标题栏下沿）。禁止 .content 之下再出现第二个 overflow:auto 祖先（双滚动条 / 标题跟着滚）。

.main  100vh · flex column · 不滚
├─ .topbar ① 固定 · 不滚
├─ .titlebar ② 固定 · 不滚
└─ .content ③ 唯一 overflow:auto ↕
├─ search / conditions  随内容滚走（不 sticky）
├─ list-head  sticky → pin 到 .content 顶
└─ thead  sticky → pin 在 list-head 之下
✓ 豁免：沉浸式全屏页（workbench / onboard / invite-email）无 topbar，但内部仍须单一滚动容器。
