Active filters（活动过滤芯片）

无论页面有无高级搜索，只要存在 ≥1 个已生效（applied）条件，就在条件区与列表卡之间渲染一行 Active filters 芯片。 芯片把「当前在过滤什么」显性化，并提供逐条 × 的撤销入口。行最左固定渲染 ACTIVE FILTERS: overline 前缀（2026-06-10 修订）。空态整行 display:none，不占位。

FIX

去掉「Clear all」，保留逐条 ×

移除「Clear all」：它会一键重置 applied 并触发一次无条件空查询，与「重搭条件」的真实意图不符（大数据列表上还会误拉全量）。 保留每条芯片的 ×：移除一条 = 立即把该条 applied 重置为默认并重查（回第 1 页），同时同步对应 draft 控件，保持条件区与芯片一致。

芯片样式即 AppliedChip 组件（2026-06-10 修订）：高 24、全圆角、底 --color-primary-50、边 primary-500@30%、文字 --color-primary-700；内容为 Label: Value 同行文本（12px，label 500 / value 400）；× 为 16×16 命中区（无描边），hover 底 primary-100。行前缀 ACTIVE FILTERS:（uppercase 10px/600/0.08em、--fg3）随行显隐。禁止手写芯片，统一复用组件。
