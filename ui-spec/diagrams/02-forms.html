新建 / 编辑表单 + 分步向导底栏

统一 <FormPage> / <FormWizard> 外壳，一律走 .page，禁止自画整屏头栏。 操作按钮放标题栏右侧（Cancel secondary + 主操作 primary），与详情页一致；不再用 sticky 底栏。 逻辑分组 ≥3 用 Stepper 分步向导，否则单页表单。表单/详情内容居中（max-width 1200），不铺满。

分步向导底栏 · WizardFooter

全部右对齐 · 退出由标题栏返回箭头承担

底部「上一步 / 下一步 / 末步主操作」统一收敛到 <WizardFooter>：.wizard-foot = padding-top:16 + 顶部 1px 分隔线，全部右对齐。 上一步 = secondary + 前置 chevL + 文案「Back」（第 1 步 disabled 并保留）；下一步 = primary + 后置 chevR + 文案「Next」；末步 = primary + check + 上下文动词（如 Create order）。向导底栏不放 Cancel。
