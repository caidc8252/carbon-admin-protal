Loading 加载态

加载提示统一为「按区域选型 + 单一组件」：单一 <Spinner size> 与 <Skeleton variant>（text/card/table-rows/avatar），删除各文件自写的 Spinner / SkeletonRows。 延迟出现：<300ms 不显示任何 loading（避免闪烁）。占位即布局：骨架尺寸/列数与真实内容一致，加载完成不发生跳动（CLS=0）。
