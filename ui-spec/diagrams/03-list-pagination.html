FIX

分页：三区块 · 去「跳转到第 N 页」

只保留 Rows per page（默认 25，选项 10/25/50/100）· Showing X–Y of N（tabular-nums）· 页码器（≤7 全展开，更多则首/末/当前±2 + …）。移除「Go to page ___ Go」；改每页行数自动回第 1 页。

NEW

行操作：图标 + 悬浮 tooltip + 受控动词

行右操作 = 纯图标按钮（30×30）+ tooltip。0 个→整行可点 + 行尾 chevR；1–2 个→图标并排（中性在前、破坏性最后）；≥3 个或含破坏性→收进竖向三点 kebab。一行只用一种承载，不混用。除行尾 chevR 外禁止无 tooltip 的纯图标。
