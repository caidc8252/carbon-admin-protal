日期与时间格式

全站统一为美式（en-US）格式，分三形态：仅时间 / 仅日期 / 日期 + 时间。 数字一律 font-variant-numeric: tabular-nums 等宽（数据语态）。本章取代 README 的 ISO 示例（2026-05-19 14:22:08），为门户唯一时间格式事实来源。
