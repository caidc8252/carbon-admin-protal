# Flows 业务流程与规则目录

本目录收录各功能模块的**行为层**文档:业务规则、状态机、处理流程图 / 时序图、跨模块关联与后台处理、开放问题登记。它回答的是「**怎么动、动了之后还触发什么**」,与 `models/`(是什么)。

> 本目录是**当前状态文档**,不是变更流水账。规则就地编辑,不记 changelog;历史需要时查文件版本历史。
> 新建格式请直接复制 [`_template.md`](./_template.md)。

## 流程清单

| 模块 | 文件 | 描述 |
| --- | --- | --- |
| Customers 客户 | [`customers.md`](./customers.md) | 客户行为层。**后台 / 跨模块（重点）**：首位 Admin 激活触发实体转 Active 与门户分工、合同 Suspend 的网关 / 邀请 / 订单后台关联处理、权益被设备 / 应用下游消费计费、ISO 下游商户与 Merchant 门店设备的只读桥接、脱敏与 Reveal 记审计。**骨架**：实体两态（Onboarding→Active，无客户级 LOCKED）、新建向导、合同家族与状态机（添加即时生效 / Suspend·Resume·Terminate / EXPIRED 派生 / Pilot 类型与转正）、按类型的合同权益、单一 Admin 激活邀请（普通操作员由客户自管）。 |
| Products 商品 | [`products.md`](./products.md) | 商品行为层。**后台 / 跨模块（重点）**：整个 Sales 域（商品/分类/订单等）只在平台 ADMIN 后台操作、不对客户开放；分类属性来源自管或绑定设备型号，改分类属性会自动同步到在售商品中用到该属性的 SKU、应用前先提示影响范围；已下过单的 SKU 锁定属性组合、不可删除（无订单关联的孤儿 SKU 在组合失效时清除）、改价直接生效无额外拦截；下单快照商品信息且成交价可覆盖目录价，使历史订单免受目录变更影响；上下架对可下单的门控；所有变更记审计。**骨架**：商品生命周期（草稿→上架→下架，无审批）、挂叶子分类、属性取分类子集、SKU 交叉组合派生与展示名、无库存、样机/量产改由订单类型区分、分类删除限制、不允许同名商品。 |
| Catalog 选购 | [`catalog.md`](./catalog.md) | 选购/下单前台（运营替客户下单）行为层。**后台 / 跨模块（重点）**：替客户下单需选客户、计费收货归该客户（继承 Sales 域 ADMIN 基线）；只挑得到在售商品+在卖 SKU、无库存；下单按当时 SKU 快照建行项且单价可逐行覆盖目录价；结算把购物车组装成订单落 orders；合计为 0（满折/免费）直接待发货跳过收款、否则待付款；折扣按比例⊕按金额二选一；结算必选是否样机；购物车跨刷新留存、同 SKU 合并。**骨架**：浏览（两级分类标签+本页搜索）、商品详情（选项/数量/改价/加购或直购）、购物车（改选项/量/价/移除/清空/再加一个）、结算三步（商品与数量+是否样机+折扣 → 客户与收货 → 复核创建）。 |
| Orders 订单 | [`orders.md`](./orders.md) | 订单（下单到发货主线）行为层。**后台 / 跨模块（重点）**：订单由 Catalog 结算生成、行项是下单时快照不回查目录；最终态即已发货（无 Delivered）；系统不接真实支付、收款/退款仅人工标记；合计为 0 的免费单跳过收款直接待发货、否则待付款；标记收款一次性全额记方式/流水/经办人；发货把待发货推进到已发货、样机订单发货前须绑齐设备；发货绑定仅样机订单用 6 位授权码逐台绑、记录写设备表（生产机订单直接发货不绑）、发货前可解绑发货后锁定；取消按已付未付自动分流（未付→已取消无退款、已付→已退款退全额、仅全额退）；订单创建后整单不可改、发货后只能整单取消。**骨架**：订单列表、详情 Overview（状态流水线+行项+金额+客户收货+操作）、订单类型样机/量产下单时定只读展示。状态机：待付款→待发货→已发货 + 取消/退款终态。 |
