Reference Specification

TOMS Carbon — Design System 2.0

The single source of truth for the Carbon Admin Portal. Every value here is extracted from the project's current final state — assets/tokens.css, components.css, and the locked CLAUDE.md conventions. Nothing is invented or carried over from a prior system.

Source of truth · OKLCH color space · Light + Dark · Geist / Geist Mono

01 — Design Principles

Principles

Five rules that govern every screen. When a decision is ambiguous, these win.

01

Reduce variables, not pixels

Same function → same component, spacing, radius, and icon container. We add a token before we add a one-off value. Fewer choices = a calmer, more trustworthy product.

02

Quiet by default

One filled primary CTA per screen. Color is reserved for status and meaning — never decoration. No gradients, no background images, no accent-on-everything.

03

Token-driven, theme-aware

Components never hardcode color, radius, or spacing. Everything reads a token so light/dark and future retunes cascade from one place.

04

Density with air

Operator tooling is information-dense, but rhythm is fixed: 24px between sections, 20px inside cards, 16px from search to table. Content scales by paging/sectioning — never by squeezing spacing.

05

Data is monospaced

IDs, serials, timestamps, money, %, versions use Geist Mono + tabular-nums so columns align and numbers are scannable.

06

Hierarchy through layering

Control radius (10) < inner/icon (12) < card (16) < modal (20) is an intentional elevation language, not inconsistency.

Icon system

Two distinct families — do not mix.

Functional UI icons — stroke (<Icon>)

  • Line/outline, 1.5–2 stroke, currentColor
  • 13–16px inline; 28px .iconbtn hit target
  • Used for actions, nav, affordances

Object / entity tiles — filled (<ObjectTile> / avatar)

  • Container 40×40, radius 12, glyph ~20
  • Light tinted same-hue surface + soft border
  • Avatars: neutral --avatar-bg/fg tile, 2-letter initials
  • Forbidden: outline/stroke-only object glyphs, gradient avatars, mixed styles

04 — Patterns

Page patterns

List page

  • Page head — full-bleed bg-2 band, 16·24 padding, 1px bottom line, title left + primary CTA right.
  • Toolbar — sticky .list-toolbar-wrap (16px above/below): SearchBar (click-Search / Enter) + Active-filters chips with Clear-all pill.
  • List card — sticky "N unit" head + sticky thead; standard Pagination footer (unit + divider).
  • Rhythm — 24 between blocks · 16 search→table · 20 card inner.

Detail page

  • Header band — .det-band 16·24; 24/600 title; status/meta chips; Tabs (42 high) flush to band's lower edge.
  • Body — two columns (main + 320 sidebar), 24px column gap and card-stack gap.
  • Fields — .kv2 vertical grid; numbers mono + tabular.

Drawer / Modal / Advanced filter

  • Panel header (standard) — title + description + close (.iconbtn 28×28, borderless), 1px bottom divider, flat bg-2.
  • Advanced filter — right-side Drawer (≤560), footer Reset (secondary, left) + Apply & Search (primary, right).
  • Modal radius 20 · Drawer radius 20 · dimmed --color-bg-overlay scrim.

05 — Design Tokens

Developer handoff

Tokens are the contract. Components read these — never hardcode. CSS variables ship today in assets/tokens.css; the Tailwind preset below maps the same names.

CSS variables (excerpt)

/* radius — DS 2.0 */
--radius-sm: 4px;   /* tag, kbd, checkbox */
--radius-md: 10px;  /* button, input, select, search */
--radius-lg: 12px;  /* icon container 40×40, KPI tile */
--radius-xl: 16px;  /* card, table, list */
--radius-2xl: 20px; /* modal, drawer */

/* spacing — 4px grid */
--space-4: 16px; --space-5: 20px; --space-6: 24px;

/* primary CTA (theme-aware) */
--color-primary-700: oklch(24% .06 262);   /* light */
[data-theme=dark] --color-primary-700: oklch(88% .004 260);

/* control sizing */
--control-height-md: 36px;

Tailwind preset (maps to the same vars)

theme: { extend: {
  borderRadius: { sm:'4px', md:'10px', lg:'12px', xl:'16px', '2xl':'20px' },
  spacing: { 1:'4px',2:'8px',3:'12px',4:'16px',5:'20px',6:'24px',8:'32px' },
  colors: {
    primary: { 700:'var(--color-primary-700)', 50:'var(--color-primary-50)' },
    success: 'var(--color-success-500)', warning:'var(--color-warning-500)',
    error: 'var(--color-error-500)', info:'var(--color-info-500)',
    bg: { 1:'var(--color-bg-1)',2:'var(--color-bg-2)',3:'var(--color-bg-3)' },
  },
  fontFamily: { sans:'var(--font-family-sans)', mono:'var(--font-family-mono)' },
}}
// dark mode: ['class','[data-theme="dark"]'] — all colors are vars, so it's automatic.

Component spec contract

  • Button → height --control-height-md, radius --radius-md, one primary/screen.
  • Card → radius --radius-xl, padding --space-5, border + --shadow-1.
  • Modal/Drawer → radius --radius-2xl, scrim --color-bg-overlay.
  • Icon container → 40×40, radius --radius-lg, glyph 20.
  • Field → .kv2 vertical, label 12/500 above.
