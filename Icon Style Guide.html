TOMS Design System · Iconography

Object Icon Style Guide

One unified style for every object/entity thumbnail across TOMS — a filled glyph inside a color-block tile. Product-ized, card-like, never outline. This is the single sanctioned treatment; all new pages inherit it.

Two icon roles

The rule applies to object icons. Functional UI icons are a separate, intentionally different role.

Object icons — filled tile

Represent a thing: a product, device, app, merchant, customer, firmware build. Always a filled glyph in a tinted tile. This guide governs these.

Functional UI icons — stroke

Affordances: nav, buttons, chevrons, search, close, filter, bell. These stay 1.5px stroke (the <Icon> set) per TOMS DS — do not fill them.

Anatomy

Fixed proportions and a token-driven palette keep every tile consistent at any size.

Container
Rounded tile, radius 8 (large sizes step to 12 / 16), 1px subtle border.
Glyph
Solid fill (currentColor), 24×24 source, rendered at ≈ 0.52× the tile.
Surface
DS semantic hue, light tint — oklch(96% 0.03 H). Dark mode: oklch(26% 0.045 H).
Glyph color
Same-hue, mid — oklch(50% 0.13 H). Dark: oklch(80% 0.10 H).
Visual weight
One per row/header. Quiet, legible at a glance — never a saturated block.

Size scale

List rows use 42. Detail headers use 56. Dense tables may use 28–36. Glyph always scales with the tile.

Glyph library

Each object category ships a filled glyph + a fixed hue. Pass a category preset, or a custom glyph + hue for new types.

In context

How the tiles read in a list — one consistent column, distinguishable by hue + glyph, never by icon style.

Do & Don't

Do — filled glyph, tinted tile
Solid glyph, soft same-hue tile. Product-ized and consistent.
Don't — outline glyph in a neutral tile
No stroke-only icons for objects. No mixing styles in one column.

Usage

Use the shared component — never hand-roll a tile. Defined in shared.jsx as window.ObjectTile.

// preset: color + glyph by category
<window.ObjectTile cat="device" />
<window.ObjectTile cat="accessory" size={56} />

// custom glyph + hue for a new object type
<window.ObjectTile glyph="app" hue={300} />

// presets: device · accessory · service · app · merchant
//          customer · firmware · card · file · order
